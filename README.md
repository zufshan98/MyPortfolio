# 💼 Personal Portfolio

A modern, responsive portfolio website built with **React** and **Vite** to showcase my projects, technical skills, certifications, and journey as a Frontend Developer. Designed with a soft pastel aesthetic, smooth animations, and a mobile-first approach, the portfolio provides an engaging experience across all screen sizes.

---

## 🌐 Live Demo

**Website:** https://my-portfolio-jet-tau-53.vercel.app/

---

## ✨ Features

- 🌸 Clean, modern, and minimal user interface
- 📱 Fully responsive design for desktop, tablet, and mobile
- 🎞️ Smooth animations powered by Framer Motion
- 🧑‍💻 Interactive About section
- 🛠️ Categorized technical skills
- 🚀 Project showcase with live demos and GitHub repositories
- 📚 Learnings, certifications, and achievements section
- 📄 Resume download
- 📧 Contact form powered by EmailJS
- 📬 Direct email support
- 📱 Mobile navigation menu
- 🎨 Thoughtfully designed pastel-themed interface

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/yourusername/portfolio.git
```

### Navigate to the project

```bash
cd portfolio
```

### Install dependencies

```bash
npm install
```

### Run the development server

```bash
npm run dev
```

The application will be available at:

```
http://localhost:5173
```

---

## 📦 Build for Production

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```
